Política de Privacidade — Leitor

Última atualização: 11 de novembro de 2026.

Quem usa

O Leitor é usado exclusivamente pelo seu dono, em computador próprio. Não há outros usuários.

Quais dados são acessados

Com a autorização do dono, a ferramenta lê as mensagens do Gmail do próprio dono para pesquisar e organizar comunicados recebidos por ele.

A permissão pedida ao Google é somente leitura (gmail.readonly): a ferramenta não envia, não apaga e não altera mensagens.

Como os dados são tratados

  • As mensagens são lidas no computador do dono e podem ser resumidas por um assistente de inteligência artificial usado pelo próprio dono, apenas para atender aos pedidos dele.
  • Nenhum dado é compartilhado, vendido ou transferido a terceiros para outros fins.
  • Nenhum dado é usado para publicidade, análise de comportamento ou treinamento de modelos de inteligência artificial.
  • Este site não usa cookies nem ferramentas de rastreamento.

Uso das APIs do Google

O uso de informações recebidas das APIs do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
