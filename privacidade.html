Política de Privacidade — Espelho

Última atualização: 11 de setembro de 2026.

Quem usa

O Espelho é usado exclusivamente pelo seu dono, em computador próprio. Não há outros usuários.

Quais dados são acessados

Com a autorização do dono, a ferramenta acessa o Google Drive do próprio dono apenas para criar e atualizar cópias sincronizadas dos arquivos dele.

A permissão pedida ao Google é a mais estreita disponível (drive.file): a ferramenta só enxerga e altera os arquivos e pastas que ela mesma criou. Os demais arquivos do Drive ficam fora do seu alcance.

O que não é feito

  • Nenhum dado é compartilhado, vendido ou transferido a terceiros.
  • Nenhum dado é usado para publicidade, análise de comportamento ou treinamento de modelos.
  • Este site não usa cookies nem ferramentas de rastreamento.

Uso das APIs do Google

O uso de informações recebidas das APIs do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
